# MOOD BITE - AI RECIPE RECOMMENDER ACCORDING TO YOUR MOOD
MoodBite uses Google Gemini AI to suggest personalized recipes based on your current emotional state

for preview of this documentation use *ctrl+shift+v*
## Setup

```
# Install dependencies
npm install 

# Start Development
npm run dev
```

## TechStack
1. React + Vite
2. Tailwind Css
3. Google Gemini api 


## Steps 
1. Install React from vite.
2. Install Tailwind css for vite.
3. Clean up and check if the tailwind css works or not.
